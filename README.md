# ITSC AutoHotKey

An IT toolkit for anyone using AHK scripting in the workplace or at home.

## Overview

These AHK libraries were developed for the need of better IT automation.

## Teach Stack

- AHK Scripting
- AHK V2.0 Runtime
- AHK Compiled Executables

## Libraries

- NetworkTools - CMD Commands for Networking
- OpenTools - User Specified IT Applications. (Change local paths here)
- ClipBoardTools - Copy & Paste Automation
- InDevelopment - Function Testing (Use at your own Risk)

## Status

Work in progress - subjective hotkeys + mouse button interoprability
Currently in research & development for universal IT workflows.
